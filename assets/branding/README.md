# Approved GLEECH artwork

`g.png` is the approved transparent G mark. `g-beta.png` is its temporary BETA
edition. These original AI-generated assets are retained so icon builds are
reproducible; unselected concepts and generation prompts stay in a local archive.

`node tooling/build-icon.mjs` and `--beta` generate the PNG/ICO resources used by
the Windows app and installer. The S indicator is a separate code-native UI mark.
