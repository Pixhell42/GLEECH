# Test image attribution

`astronaut.png` is the 512 × 512 NASA portrait of Eileen Collins, distributed as
`skimage.data.astronaut`. Scikit-image identifies it as public domain, with no known
copyright restrictions. It is used to test actual subject detection on an opaque
photograph; it is not included in the desktop application's resources.

- [Scikit-image data documentation](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut)
- [Exact fixture download](https://raw.githubusercontent.com/scikit-image/scikit-image/v0.19.3/skimage/data/astronaut.png)
